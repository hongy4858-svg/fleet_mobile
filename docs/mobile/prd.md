# PRD: 기업 차량 운영 관리 및 친환경차 전환 경제성 분석 시스템 — 모바일 앱

> 웹 버전(`mobile/docs/web/prd.md`) 대비 변경 사항에 [유지] / [수정] / [신규] 를 표시합니다.

---

## 1. 프로젝트 개요 [유지]

- **프로젝트명**: 기업 차량 운영 관리 및 친환경차 전환 경제성 분석 시스템 — Expo/React Native 모바일 앱
- **과제 성격**: 산업공학과 데이터베이스 및 경제성공학 융합 실무 과제 (모바일 확장 단계)
- **핵심 목표**: 웹 버전과 동일한 Supabase 클라우드 DB에 연결하여, 차량 등록·운행·비용 기록과 경제성 분석 기능을 스마트폰에서 조회·입력할 수 있도록 한다.

---

## 2. 사용자 및 사용 장면 [수정]

### 2.1 주요 사용자 [유지]

1. **기업 차량 및 자산 관리자 (총무팀/물류운영팀)**: 차량별 운행거리, 주유/충전 비용, 정비 이력을 기록하고 현황을 추적.
2. **ESG 및 친환경 전환 기획자 (경영기획팀)**: 친환경차 전환 경제성 시나리오 검토.

### 2.2 모바일 사용 장면 [신규]

모바일 앱은 **운전 중 조작을 가정하지 않습니다.** 다음 두 가지 정차 상태에서의 사용을 전제로 합니다.

| 사용 시점 | 대표 행동 |
| :--- | :--- |
| **출발 전 정차** | 오늘 운행에 사용할 차량 확인, 전일 미입력 운행 기록 보완, 주유·충전 완료 직후 비용 입력 |
| **운행 종료 후 정차** | 당일 주행거리·비용 입력, 정비소 방문 직후 정비 비용 기록, 대시보드에서 KPI 확인 |

> 경제성 비교·분석 이력 조회는 장소에 관계없이 사무실·이동 중 자유롭게 활용할 수 있습니다.

### 2.3 해결하고자 하는 문제 [유지]

- 차량 관리·비용 데이터가 파편화되어 차량별 실제 km당 운영단가 파악이 어려움.
- 차량 교체 시 미래 운영비를 할인율 없이 단순 합산하여 잘못된 의사결정을 내리는 오류 방지.
- 웹 PC 없이 현장에서 즉시 데이터를 입력하지 못해 기록이 누락되는 문제.

## 4. 범위 (Scope) [수정]

| 영역 | 모바일 In-Scope | 모바일 Out-of-Scope |
| :--- | :--- | :--- |
| **플랫폼** | Expo Go (개발) → Android/iOS Expo 번들 | EAS Build / App Store 배포 |
| **데이터 계층** | Supabase PostgreSQL (웹과 동일 프로젝트) | 별도 모바일 전용 DB |
| **인증** | Supabase Auth (이메일/비밀번호) | 소셜 로그인, Biometric 인증 |
| **오프라인** | 미지원 (네트워크 필수) | 오프라인 캐시, 로컬 SQLite |
| **CSV 내보내기** | 미구현 (웹에서 수행 권장) | 모바일 파일 공유 |
| **PWA** | 해당 없음 | — |

## 5. 완료 기준 (Acceptance Criteria) [수정]

1. **Expo Go 실행**: `npx expo start` 후 QR 코드로 실기기에서 앱이 오류 없이 구동된다. ✅ **사용자 확인 완료**
2. **웹·모바일 데이터 공유**: 모바일에서 추가한 운행 기록을 웹에서 조회할 수 있다. ✅ **사용자 확인 완료**
3. **로그인 / 로그아웃**: 이메일·비밀번호로 로그인·로그아웃이 정상 동작한다. ⬜ 미확인
4. **차량 CRUD**: 차량 등록·수정·삭제가 모바일에서 정상 동작한다. ⬜ 미확인
5. **운행·비용 CRUD**: 운행·주유·정비 기록 추가·수정·삭제가 모바일에서 동작한다. ⬜ 미확인
6. **분석 저장·복제**: 경제성 분석을 저장하고 복제할 수 있다. ⬜ 미확인
7. **5대 하단 탭 탐색**: 대시보드 / 차량 관리 / 운행·비용 / 경제성 비교 / 분석 이력 탭 간 전환이 정상 동작한다. ⬜ 미확인
8. **학술 고지 표시**: 경제성 비교 화면에 "입력된 가상의 가정 조건에 기초한 비용 비교" 문구가 표시된다. ⬜ 미확인
