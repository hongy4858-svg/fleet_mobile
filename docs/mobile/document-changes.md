# Document Changes: 웹 vs 모바일 문서 변경 비교표

웹 버전 문서(`mobile/docs/web/`)와 모바일 버전 문서(`mobile/docs/mobile/`) 간의 주요 항목 변경 내역을 정리합니다.

---

## prd.md 변경 비교

| 항목 | 웹 버전 | 모바일 버전 | 구분 |
| :--- | :--- | :--- | :--- |
| 플랫폼 | React / Vite 웹 애플리케이션 | Expo / React Native 모바일 앱 | [수정] |
| 사용 장면 | 사무실 PC에서 웹 브라우저 사용 | **출발 전·운행 종료 후 정차 상태**에서 스마트폰 조작 | [신규] |
| 운전 중 사용 | 명시 없음 | **운전 중 조작 가정하지 않음** 명시 | [신규] |
| 기능군 구조 | 대시보드·차량관리·운행기록·경제성비교·분석이력 (5화면) | 로그인/계정·차량관리·운행비용입력·경제성분석이력 (4기능군) | [수정] |
| 네비게이션 | 좌측 사이드바 메뉴 | 하단 탭 (5탭) | [수정] |
| 완료 기준 — Expo Go 실행 | 해당 없음 | ✅ 사용자 확인 완료 | [신규] |
| 완료 기준 — 웹·모바일 데이터 공유 | 해당 없음 | ✅ 사용자 확인 완료 | [신규] |
| 완료 기준 — 나머지 CRUD / 분석 | 모두 ✅ 완료 | ⬜ 미확인 (실기기 검증 전) | [수정] |
| CSV 내보내기 | ✅ In-Scope | Out-of-Scope (웹에서 수행 권장) | [수정] |
| PWA | ✅ 구현 완료 | 해당 없음 | — |
| 데모 모드 (localStorage) | ✅ 초기 로컬 단계 | 미적용 (클라우드 전용) | [수정] |
| DB / Auth / RLS | Supabase Cloud | 웹과 동일 프로젝트 공유 | [유지] |

| 항목 | PWA | Expo 앱 | 구분 |
| :--- | :--- | :--- | :--- |
